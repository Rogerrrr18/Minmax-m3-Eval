§ 01 旧方案核心问题

旧方案科学性不足的 8 个硬伤

上一份报告本质上是"演示性评测"，不是可信赖的评估。以下是我们认识到的主要问题，每个问题都对应一个系统性修复方案。

P1
自评自审
评分者是我自己，对MiniMax-m3输出天然有美化倾向，无独立第三方裁判
用 gpt-5.5 作为独立评分模型，对所有模型输出无差别评分
P2
样本量过小
Coding 9题 / Office 6题，每维度仅2-3题，统计误差估计±8~15分，结论不可靠
每维度至少30题，双场景共60题以上，确保30题维度有统计显著性
P3
代码从未实际执行
HumanEval/Spider的核心是机器判定（运行代码、比对社会接受结果），我们只是读文本
引入Docker沙箱执行环境，自动化判定代码是否通过编译/运行
P4
无标准基准实际运行
声称用了HumanEval/Spider，但实际测的是自拟题目，不是官方测试集，无可比性
直接使用各基准的官方题目集（可从对应GitHub仓库获取），确保与公开榜单可比
P5
缺少基线模型对照
80分是好是坏？没有参照，不知道MiniMax-m3比GPT-4o/Claude好还是差
同等题目测所有模型，横向对比，输出相对排名
P6
评分标准过于主观
"结构完整92分""语气专业90分"缺乏可量化定义，不同评分者结论不同
制定严格0/1机械判定标准（编译错误/运行错误/逻辑错误），gpt-5.5按规则打分
P7
坏案例仅有1个
不足以归纳能力弱点边界，需要更多失败样本来定位真实薄弱点
60题×4模型=240条输出全量分析，统计各模型的失败类型分布
P8
单次测试无稳定性
同样题目只测一次，LLM有随机性，temperature=0.2不代表完全确定
每题测5次取均值（对应HumanEval Pass@5的标准做法），或固定使用严格deterministic评价prompt

§ 05 GPT-5.5 裁判系统

GPT-5.5 独立裁判 Prompt 设计

裁判 GPT-5.5 在不知道模型身份的情况下，对 4 个模型的输出按统一标准打分，避免偏好误差。

🧑‍⚖️ GPT-5.5 裁判 System Prompt
【角色】你是一位严格、公正的AI模型评测员。你的任务是对多个AI模型在相同任务上的输出进行评分。 【原则】你不知道哪个输出对应哪个模型，只能根据质量打分。对所有模型一视同仁，严格按照标准评判。 【输出格式】你必须严格按以下JSON格式输出，不要有任何多余内容： { "task_id": "题目ID", "model_A_score": 0或1或2, "model_B_score": 0或1或2, "model_C_score": 0或1或2, "model_D_score": 0或1或2, "reasoning": "简短评分理由（50字以内）" } 【评分标准】 - Coding类题目：0=代码无法运行/结果错误，1=代码可运行但效率或风格有问题，2=代码完全正确且高效 - Office类题目：0=完全不满足要求，1=基本满足但有改进空间，2=完全满足要求 【注意】每个task_id对应一个题目，你需要输出4个模型的分数。如果某个模型输出为空或明显作弊，给0分。
📝 实际调用时的 User Prompt 示例
【评分任务】请对以下4个AI模型在同一个编程任务上的输出进行评分。 【题目ID】coding_gen_001 【题目内容】写一个Python函数，接受一个整数列表和一个目标整数，返回列表中所有两数之和等于目标的索引对。要求时间复杂度O(n)。 【模型A输出】 ```python def solve(nums, target): seen = {} result = [] for i, num in enumerate(nums): complement = target - num if complement in seen: result.append((seen[complement], i)) if num not in seen: seen[num] = i return result ``` 【模型B输出】 ```python def solve(nums, target): result = [] for i in range(len(nums)): for j in range(i+1, len(nums)): if nums[i] + nums[j] == target: result.append((i, j)) return result ``` 【模型C输出】 ```python def solve(nums, target): if not nums: return [] # O(n²)解法 result = [] for i in range(len(nums)): for j in range(len(nums)): if i != j and nums[i] + nums[j] == target: result.append((i, j)) return list(set(result)) ``` 【模型D输出】 抱歉，我不太理解这个需求。 请按上述JSON格式输出评分结果。

import openai import json import time import random from concurrent.futures import ThreadPoolExecutor, as_completed # ============ 全局配置 ============ JUDGE_MODEL = "gpt-5.5" JUDGE_URL = "http://www.opcrouter.online/v1" JUDGE_KEY = "sk-fPpoLMFQf6LZ7NEWsZo4zcpZLwgbcbmaPvMYtqHtKudHNlyV" MODELS = [ {"name": "MiniMax-m3", "url": "https://api.minimax.chat/v1", "key": "sk-api-a5kkIYxSCEO-...", "id": "MiniMax-m3"}, {"name": "deepseek-v4-flash", "url": "http://www.opcrouter.online/v1", "key": "sk-1VV3vI8HgxR3...", "id": "deepseek-v4-flash"}, {"name": "mimo-v2.5-pro", "url": "http://www.opcrouter.online/v1", "key": "sk-9CNkcxVPX4QF...", "id": "mimo-v2.5-pro"}, {"name": "kimi-k2.6", "url": "http://www.opcrouter.online/v1", "key": "sk-1VV3vI8HgxR3kYYRI8byG1dD1QSqVwHmXdfqyiDkjsvaajZB", "id": "kimi-k2.6"}, ] JUDGE_SYSTEM_PROMPT = """【角色】你是一位严格、公正的AI模型评测员。 【原则】你不知道哪个输出对应哪个模型，只能根据质量打分。 【输出格式】严格按JSON格式输出： {"task_id":"xxx","model_A_score":0或1或2,"model_B_score":0或1或2,"model_C_score":0或1或2,"model_D_score":0或1或2,"reasoning":"..."}""" def call_model(url, key, model_id, prompt, system_prompt=None): messages = [] if system_prompt: messages.append({"role": "system", "content": system_prompt}) messages.append({"role": "user", "content": prompt}) client = openai.OpenAI(api_key=key, base_url=url, timeout=60) response = client.chat.completions.create(model=model_id, messages=messages, temperature=0, max_tokens=1024) return response.choices[0].message.content def batch_call_model(model, tasks, system_prompt=None): """并行调用单个模型处理一批任务""" results = {} for task in tasks: output = call_model(model["url"], model["key"], model["id"], task["prompt"], system_prompt) results[task["task_id"]] = output time.sleep(0.3) return model["name"], results def call_judge(all_outputs_per_task, judge_tasks): """GPT-5.5批量盲评""" judge_client = openai.OpenAI(api_key=JUDGE_KEY, base_url=JUDGE_URL, timeout=60) judgments = {} for task in judge_tasks: task_id = task["task_id"] outputs = all_outputs_per_task[task_id] # dict: model_name -> output # 构建盲评prompt user_prompt = f"""【评分任务】请对以下4个AI模型在同一个任务上的输出进行评分。 【题目ID】{task_id} 【题目内容】{task['prompt']} """ for i, (model_name, output) in enumerate(outputs.items()): user_prompt += f"\n【模型{chr(65+i)}输出】\n{output[:500]}" user_prompt += "\n请严格按JSON格式输出评分结果。" resp = judge_client.chat.completions.create( model=JUDGE_MODEL, messages=[ {"role": "system", "content": JUDGE_SYSTEM_PROMPT}, {"role": "user", "content": user_prompt} ], temperature=0, max_tokens=256 ) raw = resp.choices[0].message.content try: # 提取JSON start = raw.find("{") end = raw.rfind("}") + 1 judgments[task_id] = json.loads(raw[start:end]) except: judgments[task_id] = {"error": raw} time.sleep(0.5) return judgments def run_scientific_eval(): # Step 1: 加载任务集（以本地JSON文件形式） with open("tasks.json", "r", encoding="utf-8") as f: tasks = json.load(f) # Step 2: 并行调用所有模型 all_outputs = {} # task_id -> {model_name -> output} with ThreadPoolExecutor(max_workers=4) as executor: futures = {} for model in MODELS: future = executor.submit(batch_call_model, model, tasks) futures[future] = model["name"] for future in as_completed(futures): model_name = futures[future] outputs = future.result() for task_id, output in outputs.items(): if task_id not in all_outputs: all_outputs[task_id] = {} all_outputs[task_id][model_name] = output # Step 3: 保存原始输出 with open("raw_outputs.json", "w", encoding="utf-8") as f: json.dump(all_outputs, f, ensure_ascii=False, indent=2) # Step 4: GPT-5.5盲评 judgments = call_judge(all_outputs, tasks) # Step 5: 生成对比报告 report = {} for model in MODELS: scores = [] for task in tasks: task_id = task["task_id"] model_idx = list(MODELS).index(model) score_key = f"model_{chr(65+model_idx)}_score" if task_id in judgments and score_key in judgments[task_id]: scores.append(judgments[task_id][score_key]) report[model["name"]] = { "avg_score": sum(scores)/len(scores) if scores else 0, "total": len(scores), "scores": scores } with open("eval_report.json", "w", encoding="utf-8") as f: json.dump(report, f, ensure_ascii=False, indent=2) return report, judgments if __name__ == "__main__": report, judgments = run_scientific_eval() print("✅ 科学评测完成，结果已保存到 eval_report.json")
