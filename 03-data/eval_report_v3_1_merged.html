§01 评测方法说明

本报告是 v3.0 评测的升级版本，核心改进在于引入多裁判交叉验证机制，以消除单一裁判模型可能带来的评分偏见。

裁判 1：GPT-5.5

OpenAI 最新旗舰模型，作为通用能力基准裁判，对全部 4 个模型的输出进行盲评。

裁判 2：deepseek-v4-flash

DeepSeek 开源系列模型，作为国产模型视角的补充裁判，独立给出 0-10 分评分。

裁判 3：MiniMax-M3

被评测模型自身作为裁判，用于检测 GPT-5.5 是否存在系统性的"外来裁判偏见"。

评分流程

  1. 每个裁判独立调用，不知道当前评分对象对应哪个模型；
  2. 每个裁判对每个模型、每个维度单独给出 0-10 分及理由；
  3. 最终得分为三个裁判评分的算术平均值，并计算标准差反映裁判分歧；
  4. 若某裁判缺失评分，取剩余裁判平均（本报告三裁判覆盖率均为 100%）。

🚨 关键发现：代码补全是全行业灾难性短板

在代码补全维度，四个模型得分均极低：mimo-v2.5-pro 3.43、deepseek-v4-flash 0.97、MiniMax-m3 0.59、kimi-k2.6 0.43。即使第一名 mimo 也只有 3.43 分，远低于其他维度。

这不是模型能力问题，而是评测设计问题。现有题目要求模型补全 CodeSearchNet 中的函数中间片段，但模型往往输出完整函数而非精确补全，导致三裁判均给出低分。v3.0 单 GPT-5.5 裁判给出的 1.02-3.38 分已被证明过于严苛且不区分模型优劣。建议未来版本重构代码补全评测集，或从报告中暂时剔除该维度。

📌 核心修正结论

v3.0 的最大误判：单 GPT-5.5 裁判让 deepseek-v4-flash 以 7.92 分位居第一，领先 mimo 0.09 分、MiniMax 0.10 分。但加入 deepseek 自身和 MiniMax 作为裁判后，deepseek 被下调 0.16 分，MiniMax 被下调 0.19 分，而 mimo 保持不变。这说明：

  • GPT-5.5 对国产模型存在轻微 but 系统性的"慷慨偏见"；
  • mimo-v2.5-pro 的得分跨越裁判视角最稳定，是真正意义上的第一名；
  • MiniMax-m3 的真实能力与 deepseek 的差距（0.13 分）比单裁判显示的（0.10 分）略大。

§05 MiniMax-m3 专项分析

相对优势维度

  • 算法能力 9.18 分：全场第 2，仅次于 deepseek 的 9.25，但高于 mimo 的 9.08。这是 MiniMax 最扎实的维度。
  • 邮件处理 7.81 分：全场第 1，在商务邮件场景中表现最好。
  • 表格处理 7.79 分：全场第 2，仅次于 deepseek 的 7.86。

相对劣势维度

  • 代码补全 0.59 分：与 kimii 并列倒数，但该维度全行业崩盘，参考价值有限。
  • 文档撰写 6.94 分：全场并列倒数第 1，仅略高于 kimi 的 6.93。说明 MiniMax 在长文本生成和企业文档写作上还有提升空间。
  • SQL查询 8.26 分：看似不低，但落后于 deepseek（8.47）和 mimo（8.35），在数据分析场景中没有优势。

三裁判对 MiniMax 的评分差异

从合并评分中的标准差来看，MiniMax 在主观类维度（文档撰写、邮件处理、多语言办公）上的裁判分歧通常大于 deepseek 和 mimo，说明其输出风格在不同裁判视角下评价波动较大。在客观类维度（算法能力、代码生成、错误修复）上分歧较小。

§06 裁判一致性分析

三裁判交叉验证的最大价值在于暴露评分偏见。从合并结果观察：

  • 高一致性维度：算法能力、代码生成、错误修复（标准差普遍 < 1.5），说明这些维度评分标准客观，三裁判意见趋同。
  • 低一致性维度：代码补全、文档撰写、多语言办公（标准差可达 2-3 分），说明这些维度主观性强，不同裁判对"好"的定义差异大。
  • 特殊现象：MiniMax-M3 作为裁判时，给 deepseek-v4-flash 的分数在多个维度上显著低于 GPT-5.5，而对 mimo 的评分相对更接近 GPT-5.5。这印证了"同类模型之间存在评分竞争偏见"的假设。

💡 方法学反思

多裁判验证确实修正了单 GPT-5.5 裁判的部分偏见，但也引入了新的问题：让被评测模型（MiniMax-M3、deepseek-v4-flash）担任裁判，可能存在"打压竞争对手"的动机。v3.2 可考虑引入更多第三方裁判（如 Claude-4、Gemini-2.5）来进一步稀释这种偏见。

§07 最终结论与建议

对 v3.0 报告结论的覆盖

  1. 原结论"deepseek-v4-flash 综合第一"被修正：在三裁判平均下，mimo-v2.5-pro 以 7.83 分排名第一，deepseek 以 7.76 分降至第二。
  2. 原结论"MiniMax-m3 与 mimo 差距仅 0.01 分"被修正：真实差距为 0.20 分，MiniMax 排名第 3 但与 deepseek 的差距仅 0.13 分。
  3. 原结论"代码补全是明显短板"被强化：所有模型在该维度得分均极低，应当被视为评测设计缺陷而非模型能力差异。
  4. 新增结论"MiniMax 在邮件处理场景有真实优势"：7.81 分为四模型最高，且三裁判一致认可。

对 MiniMax-m3 的客观定位

在三裁判独立验证下，MiniMax-m3 的综合能力位居四模型第 3，与第 2 名 deepseek 差距 0.13 分，与第 1 名 mimo 差距 0.20 分。其核心优势在算法推理和邮件处理，核心短板在文档撰写和代码补全（后者受评测设计影响）。

考虑到 top3 模型得分均在 7.6-7.8 区间，差距小于 0.25 分，实际业务选型中维度匹配度比综合排名更重要。
